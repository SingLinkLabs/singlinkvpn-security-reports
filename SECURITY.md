# Security policy

Do not report product vulnerabilities, private endpoints, credentials, node addresses, customer data, or exploit details in a public GitHub issue.

Use the official SingLinkVPN security contact path at <https://singlinknews.com/contact>. Include the affected version, a minimal reproduction, and a safe contact method. Do not test production systems without written authorization.

Public issues may be used for broken source links, incorrect metadata, checksum mismatches, or citation corrections that do not expose sensitive information.
